# Taller: observa el gateo con Screaming Frog

RECORDATORIO TEÓRICO Antes de empezar, recordemos los conceptos clave. El "gateo" (crawling en inglés) es el proceso mediante el cual un robot de un motor de búsqueda recorre las páginas de un sitio web siguiendo los enlaces internos y externos. El robot parte de una URL, descubre los enlaces que contiene, los visita, y así sucesivamente, construyendo un mapa del sitio. Screaming Frog SEO Spider es una herramienta de escritorio que simula este comportamiento: se comporta como un robot y te muestra todo lo que un motor de búsqueda vería al rastrear tu web. El modelo mental es sencillo: imagina el sitio como una red de habitaciones (páginas) conectadas por puertas (enlaces). El robot solo puede entrar en una habitación si existe una puerta que lo lleve hasta ella. Si una página no tiene ningún enlace apuntando hacia ella, el robot no la encontrará (página "huérfana"). Errores frecuentes: confundir una página que existe con una página rastreable; ignorar los códigos de estado HTTP (un 404 significa página inexistente, un 301 una redirección); o pensar que todas las páginas del sitio son indexables cuando algunas están bloqueadas por robots.txt o por la etiqueta "noindex". Mini-ejemplo: si rastreas un blog y descubres 50 URLs con código 200 (correctas), 5 con código 404 (rotas) y 3 con "noindex", ya tienes un diagnóstico inicial de la salud técnica del sitio.
