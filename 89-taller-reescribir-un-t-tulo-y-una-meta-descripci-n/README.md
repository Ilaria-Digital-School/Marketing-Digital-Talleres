# Taller: reescribir un título y una meta descripción

Recordatorio teórico: La etiqueta de título (title tag) y la meta descripción (meta description) son dos elementos HTML fundamentales que Google muestra en las páginas de resultados (SERP). El título es el enlace azul clicable que resume el contenido de la página; la meta descripción es el fragmento de texto gris que aparece debajo. Aunque la meta descripción no es un factor de posicionamiento directo, influye enormemente en la tasa de clics (CTR), y el título sí impacta el ranking. Modelo mental: piensa en el título como un titular de periódico que debe contener la palabra clave principal cerca del inicio, respetar unos 50-60 caracteres (o ~600 píxeles) y despertar el deseo de hacer clic. La meta descripción debe tener entre 120 y 155 caracteres, incluir la palabra clave de forma natural, resumir el valor de la página y terminar con una llamada a la acción. Errores frecuentes: escribir títulos genéricos («Inicio», «Servicios»), duplicar títulos en varias páginas, superar el límite de caracteres (Google trunca con «…»), rellenar de palabras clave (keyword stuffing) o dejar la meta descripción vacía dejando que Google la genere automáticamente. Mini-ejemplo: en lugar de «Zapatos - Nuestra tienda», escribe «Zapatillas de running para mujer | Envío gratis 24h». La meta descripción: «Descubre nuestra colección de zapatillas de running para mujer. Amortiguación premium, tallas 35-42 y devolución gratuita. ¡Compra hoy!».
