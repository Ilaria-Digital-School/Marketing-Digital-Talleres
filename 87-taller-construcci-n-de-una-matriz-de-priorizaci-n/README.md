# Taller: construcción de una matriz de priorización

RECORDATORIO TEÓRICO Una matriz de priorización es una herramienta visual que permite clasificar tus palabras clave (o acciones SEO) según varios criterios objetivos para decidir por dónde empezar. El modelo mental más habitual en SEO combina dos ejes principales: el potencial de negocio o impacto (volumen de búsqueda, intención comercial, valor de conversión) y el esfuerzo o facilidad de posicionamiento (dificultad de la palabra clave, competencia, autoridad de tu dominio). El cruce de estos ejes genera cuatro cuadrantes: las 'ganancias rápidas' (alto impacto, bajo esfuerzo), los 'proyectos estratégicos' (alto impacto, alto esfuerzo), las 'tareas de relleno' (bajo impacto, bajo esfuerzo) y las 'acciones a descartar' (bajo impacto, alto esfuerzo). El error más frecuente consiste en priorizar únicamente por volumen de búsqueda, ignorando la dificultad y la intención. Una palabra con 50.000 búsquedas mensuales pero dificultad 90 y sin intención comercial rara vez merece ser el primer objetivo de un sitio nuevo. Otro error común es no ponderar los criterios: no todos pesan lo mismo. Mini-ejemplo: para una tienda de zapatillas, 'comprar zapatillas running baratas' (volumen medio, dificultad baja, intención transaccional alta) sería una ganancia rápida prioritaria, mientras que 'zapatillas' (volumen enorme, dificultad extrema, intención difusa) iría al cuadrante de proyectos estratégicos a largo plazo. --- ENUNCIADO DEL TALLER Tu objetivo es construir una matriz de priorización funcional a partir de un conjunto de palabras clave y justificar tus decisiones estratégicas.
