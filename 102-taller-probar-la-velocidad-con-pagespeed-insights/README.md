# Taller: probar la velocidad con PageSpeed Insights

RECORDATORIO TEÓRICO La velocidad de carga es hoy un factor determinante tanto para la experiencia del usuario como para el posicionamiento orgánico. Google evalúa el rendimiento de una página mediante las Core Web Vitals, un conjunto de métricas centradas en la percepción real del usuario. Las tres principales son: LCP (Largest Contentful Paint), que mide el tiempo que tarda en cargarse el elemento visible más grande; INP (Interaction to Next Paint), que evalúa la capacidad de respuesta ante las interacciones; y CLS (Cumulative Layout Shift), que cuantifica la estabilidad visual, es decir, los desplazamientos inesperados de los elementos durante la carga. PageSpeed Insights es la herramienta gratuita de Google que analiza una URL y entrega dos tipos de datos: los de laboratorio (simulados en un entorno controlado) y los de campo (recogidos de usuarios reales cuando existen). El modelo mental correcto consiste en no obsesionarse con la puntuación global sobre 100, sino en identificar los problemas concretos que la herramienta señala en la sección de "Oportunidades" y "Diagnósticos". Un error frecuente es confundir móvil y escritorio: una página puede rendir bien en escritorio y mal en móvil, y Google prioriza la versión móvil (mobile-first). Otro error habitual es ignorar que las imágenes pesadas y los scripts de terceros son las causas más comunes de lentitud.
