# Taller: uso de Ubersuggest para analizar las métricas de palabras clave

RECORDATORIO TEÓRICO La investigación de palabras clave consiste en identificar los términos que tu audiencia escribe en los motores de búsqueda para encontrar contenidos como el tuyo. Cada palabra clave se evalúa mediante varias métricas fundamentales. El volumen de búsqueda indica cuántas veces se busca un término al mes. La dificultad SEO (SEO Difficulty o SD) mide, en una escala de 0 a 100, lo difícil que es posicionarse en la primera página para esa palabra. El CPC (coste por clic) refleja el valor comercial del término en publicidad, y la competencia de pago (Paid Difficulty) muestra la presión publicitaria. A esto se suma la intención de búsqueda (informativa, transaccional, navegacional o comercial), concepto que ya has estudiado. El modelo mental correcto es buscar un equilibrio: palabras con volumen razonable, dificultad accesible para un sitio nuevo y una intención alineada con tu objetivo de negocio. A esto se le llama identificar "oportunidades" o palabras clave de cola larga (long tail), más específicas y menos competidas. Errores frecuentes: perseguir únicamente palabras de alto volumen (casi siempre muy competidas), ignorar la intención de búsqueda, o fijarse solo en una métrica aislada sin cruzar datos. Mini-ejemplo: la palabra "zapatillas" tiene un volumen enorme pero una dificultad altísima; en cambio "zapatillas running mujer talla 39" tiene menos volumen, pero una intención transaccional clara y una competencia mucho más asumible, lo que la convierte en una mejor oportunidad para un proyecto joven. --- ENUNCIADO DEL TALLER En este taller aplicarás todo lo anterior utilizando Ubersuggest,...
