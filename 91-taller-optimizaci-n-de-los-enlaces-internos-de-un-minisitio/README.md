# Taller: optimización de los enlaces internos de un minisitio

RECORDATORIO TEÓRICO La malla interna (o internal linking) es el conjunto de enlaces que conectan las páginas de un mismo sitio web entre sí. Su papel es doble: por un lado guía al usuario en su navegación, y por otro distribuye la autoridad (a menudo llamada "link juice" o "PageRank interno") entre las páginas, ayudando a los motores de búsqueda a comprender la jerarquía y la temática del sitio. Un modelo mental útil es imaginar el sitio como una ciudad: las páginas son edificios y los enlaces internos son las calles. Cuanto mejor conectada esté una página, más fácil será llegar a ella, tanto para los visitantes como para los robots de indexación. El texto de anclaje (anchor text) es el texto visible y clicable de un enlace. Debe ser descriptivo y contener, cuando sea natural, palabras clave relacionadas con la página de destino. Los errores frecuentes son: usar anclajes genéricos como "haz clic aquí", dejar páginas huérfanas (sin ningún enlace entrante), enlazar de forma excesiva y repetitiva con el mismo anclaje exacto (sobreoptimización), o no enlazar hacia las páginas estratégicas del sitio. Mini-ejemplo: en un blog de cocina, un artículo sobre "recetas de pan casero" debería enlazar con el texto de anclaje "harina de fuerza" hacia la guía de ingredientes, en lugar de escribir "más información aquí".
