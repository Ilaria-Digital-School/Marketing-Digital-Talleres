# Miniproyecto: escribe el resumen completo de palabras clave para un sitio ficticio

## Presentación del proyecto En este mini-proyecto pondrás en práctica todo lo aprendido sobre investigación de palabras clave (keyword research) para elaborar un documento profesional y accionable: el resumen completo de palabras clave (keyword brief) de un sitio web ficticio. Este entregable es exactamente el tipo de documento que un consultor SEO o un responsable de marketing digital produce al inicio de cualquier estrategia de posicionamiento orgánico. Constituye la base sobre la que se construye la arquitectura del sitio, el calendario editorial y la estrategia de contenidos. ## Escenario Elige uno de los siguientes sitios ficticios (o propón el tuyo, validando el sector): - **Opción A**: 'VerdeCasa', una tienda online de plantas de interior y accesorios de jardinería urbana. - **Opción B**: 'RutaFit', un blog y plataforma de coaching deportivo online para principiantes. - **Opción C**: 'ContaClara', un despacho ficticio de asesoría contable para autónomos y pequeñas empresas. Tu misión es actuar como el especialista SEO encargado de definir el universo de palabras clave que guiará la estrategia de contenidos de ese sitio durante los próximos 6 meses. ## Competencias que se validan - Comprender las necesidades del público objetivo y traducirlas en intenciones de búsqueda. - Conocer y utilizar las herramientas de marketing web (Google Suggest, Ubersuggest, etc.). - Analizar métricas de palabras clave (volumen, dificultad, CPC) para tomar decisiones. - Priorizar acciones y detectar oportunidades rápidas (quick wins). - Estructurar y presentar la información de forma clara y profesional. ## Alcance esperado Un resumen sólido debe contener entre...
