# Taller: identificación de los elementos clave de un SERP

RECORDATORIO TEÓRICO Un SERP (Search Engine Results Page) es la página de resultados que muestra un motor de búsqueda como Google tras una consulta. Tras haber estudiado cómo el motor rastrea e indexa la web, ahora observamos lo que el usuario ve realmente: la interfaz de salida de todo ese proceso. Un SERP moderno ya no es una simple lista de diez enlaces azules. Combina resultados orgánicos (posicionados de forma natural gracias al SEO), resultados de pago (anuncios SEA, señalados con la etiqueta «Patrocinado» o «Anuncio») y numerosos elementos enriquecidos: featured snippet (fragmento destacado en posición cero), People Also Ask (preguntas relacionadas), Knowledge Panel (panel de conocimiento), imágenes, vídeos, mapa local (Local Pack), enlaces de sitio (sitelinks) y valoraciones con estrellas (rich snippets). El modelo mental clave: cada resultado orgánico se compone de tres piezas fundamentales que el SEO puede influir directamente: la URL, el title tag (título azul clicable) y la meta description (texto descriptivo bajo el título). Estos elementos condicionan el CTR (tasa de clics). Errores frecuentes: confundir un anuncio de pago con un resultado orgánico, creer que la posición 1 orgánica está siempre arriba del todo (a menudo hay anuncios y featured snippets antes), o ignorar los elementos SERP que «roban» clics sin necesidad de visitar la web. Mini-ejemplo: al buscar «mejor cámara réflex», verás probablemente anuncios de tiendas, un People Also Ask, resultados con estrellas de valoración y artículos de comparativas.
