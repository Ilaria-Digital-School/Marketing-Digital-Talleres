# Taller: dibujo de una estructura de árbol optimizada

Recordatorio teórico: La estructura de árbol (o arborescencia) de un sitio web es la organización jerárquica de sus páginas, desde la página de inicio hasta las páginas más profundas. Se representa como un árbol invertido: la home en la cima, luego categorías principales, subcategorías y finalmente páginas de contenido o productos. El modelo mental clave es el de la 'profundidad de clics': idealmente, cualquier página importante debe ser accesible en 3 clics o menos desde la home. Una buena arborescencia distribuye el 'jugo SEO' (autoridad interna) de forma lógica, facilita el rastreo por parte de Google (crawl) y mejora la experiencia del usuario. Los conceptos previos que ya has visto se conectan directamente aquí: los enlaces internos y el texto de anclaje son los que materializan esta estructura, y las URL deben reflejar la jerarquía (por ejemplo /categoria/subcategoria/pagina). Los errores frecuentes son: crear demasiados niveles de profundidad (páginas 'huérfanas' inalcanzables), agrupar categorías de forma incoherente con la intención de búsqueda, o mezclar temáticas sin lógica semántica. También se comete el error de basar la estructura en la organización interna de la empresa en lugar de en las necesidades del usuario y las palabras clave objetivo. Mini-ejemplo: para una tienda de calzado, una arborescencia optimizada sería: Home > Zapatillas > Zapatillas de running > 'Zapatillas running para asfalto'. Cada nivel corresponde a un grupo de palabras clave con volumen de búsqueda decreciente y intención cada vez más precisa.
