# Taller: agrupar palabras clave por intención

Recordatorio teórico: La intención de búsqueda es el objetivo real que persigue un usuario cuando escribe una consulta en un motor de búsqueda. Agrupar palabras clave por intención significa organizar tu lista de keywords según lo que el usuario espera encontrar, no solo según su similitud semántica. Existen cuatro grandes tipos de intención que ya viste en capítulos anteriores: informacional (el usuario busca aprender o comprender, ej. "qué es el SEO"), navegacional (busca un sitio o marca específica, ej. "login Ubersuggest"), comercial o de investigación (compara antes de decidir, ej. "mejor herramienta SEO 2024") y transaccional (quiere realizar una acción o compra, ej. "contratar auditoría SEO"). El modelo mental clave es sencillo: cada palabra clave responde a una etapa distinta del recorrido del usuario, y cada grupo de intención debe corresponder a un tipo de contenido o página diferente (artículo de blog, landing page, ficha de producto, página de comparativa). Un error frecuente es agrupar keywords solo por tema ignorando la intención: mezclarías en una misma página "cómo funciona el email marketing" (informacional) con "software email marketing precios" (transaccional), lo que confunde tanto a Google como al usuario y perjudica el posicionamiento. Otro error es olvidar que una palabra puede tener intención ambigua y requiere analizar la SERP real para confirmarla. Mini-ejemplo: las keywords "receta pan casero", "comprar horno de leña" y "panadería cerca de mí" comparten el tema "pan" pero pertenecen a tres intenciones distintas (informacional, transaccional, navegacional/local) y exigen tres páginas separadas.
